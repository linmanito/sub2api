## 一、什么是代理商模式

代理商模式允许第三方（代理商）以**批发价**从平台采购 API 额度，然后以**自定义价格**销售给自己的客户（下游用户），赚取差价。

**简单理解：**
- 平台 → 代理商：批发价
- 代理商 → 下游用户：零售价
- 代理商利润 = 零售价 - 批发价

---

## 二、角色说明

| 角色 | 说明 |
|------|------|
| **平台管理员** | 管理整个平台，包括代理商和所有用户 |
| **代理商** | 从平台批发额度，发展和服务自己的下游用户 |
| **下游用户** | 代理商的客户，通过代理商购买和使用 API 服务 |
| **平台直属用户** | 直接在平台注册、不属于任何代理商的用户 |

---

## 三、收费模式

### 3.1 平台向代理商收费

平台管理员给代理商分配额度，按**批发价**结算。

**示例：**
- 平台标准价：$1 = 1 美元额度
- 给代理商的批发价：8 折（即 $0.8 = 1 美元额度）
- 代理商充值 $800，获得 $1000 额度

### 3.2 代理商向下游用户收费

代理商可以**自主定价**，通过设置"倍率"来调整下游用户的价格。

**倍率说明：**
- 倍率 1.0 = 成本价（不赚钱）
- 倍率 1.2 = 加价 20%
- 倍率 1.5 = 加价 50%
- 倍率 0.8 = 亏本卖（系统会警告，但允许）

**示例：**
- 代理商设置倍率 1.5
- 下游用户调用 API，实际成本 $10
- 下游用户被扣：$10 × 1.5 = $15
- 代理商利润：$15 - $10 = $5

### 3.3 下游用户付费方式

代理商可以选择两种方式向下游用户收费：

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **余额充值** | 下游用户充值余额，按量扣费 | 用量不固定的用户 |
| **订阅制** | 分配固定额度（如每月 $100） | 需要固定预算的用户 |

## 四、代理商如何获取下游用户

### 4.1 邀请码注册

1. 代理商在后台生成邀请码
2. 将邀请码发给潜在客户
3. 客户注册时填写邀请码
4. 客户自动归属到该代理商名下

### 4.2 代理商直接创建

1. 代理商在后台直接创建用户账号
2. 设置邮箱、初始密码
3. 可同时设置初始余额
4. 将账号信息发给客户

### 4.3 平台分配

平台管理员可以将已注册的"平台直属用户"分配给某个代理商。

## 五、资金流转说明

### 5.1 完整流程图

```
┌─────────┐    批发价充值     ┌─────────┐    自定义价格     ┌─────────┐
│  平台   │  ───────────────→ │ 代理商  │  ───────────────→ │下游用户 │
└─────────┘   $800 → $1000    └─────────┘    按倍率销售      └─────────┘
                               额度池                          使用API
```

### 5.2 具体示例

**第一步：平台给代理商充值**
```
平台管理员给代理商 A 充值 $1000 额度
代理商 A 账户余额：$0 → $1000
```

**第二步：代理商给下游用户充值**
```
代理商 A 给用户甲充值 $100
- 代理商 A 余额：$1000 → $900
- 用户甲余额：$0 → $100
```

**第三步：下游用户消费**
```
用户甲调用 API，实际成本 $50
代理商设置的倍率：1.2

用户甲被扣：$50 × 1.2 = $60
用户甲余额：$100 → $40
```

**第四步：代理商收益计算**
```
代理商投入：$100（划给用户甲）
用户甲消费后：$60（已消费） + $40（剩余）= $100
平台实际成本：$50

代理商收益：$100 - $50 = $50
收益率：50%（因为倍率设置为 1.2，即加价 20%，且用户甲的 $100 有 $60 被消费）
```

## 六、代理商后台功能

代理商登录后有独立的管理后台，可以：

| 功能 | 说明 |
|------|------|
| **查看余额** | 查看自己可分配的额度 |
| **用户管理** | 创建、查看、管理下游用户 |
| **充值/扣款** | 给下游用户充值或扣款 |
| **设置倍率** | 设置下游用户的计费倍率 |
| **邀请码管理** | 生成、管理邀请码 |
| **用量统计** | 查看下游用户的消费明细 |
| **订阅管理** | 给下游用户分配订阅 |
| **API Key 管理** | 帮下游用户管理 API Key |

| 功能 | 说明 |

| **升级/降级** | 将普通用户升级为代理商，或反向操作 |
| **查看全局数据** | 查看所有代理商和用户的数据 |

## 八、定价策略建议

### 8.1 给代理商的批发价

根据代理商的级别或采购量，可以设置不同的批发折扣：

| 级别 | 折扣 | 说明 |
|------|------|------|
| 普通代理 | 9 折 | 小型代理商 |
| 银牌代理 | 85 折 | 月采购 $1000+ |
| 金牌代理 | 8 折 | 月采购 $5000+ |

### 8.2 代理商的建议零售价

建议代理商设置 1.1 ~ 1.5 的倍率：
- 1.1 倍：薄利多销
- 1.2 ~ 1.3 倍：常规定价
- 1.5 倍：高端服务/小客户

## 九、常见问题

### Q1：代理商设置的倍率低于成本价怎么办？

系统会弹出警告提示，但允许代理商这样做。这种情况下代理商会亏钱，但不影响平台收益（因为额度是代理商已经买断的）。

### Q2：下游用户能看到自己属于哪个代理商吗？

可以配置是否显示。默认下游用户只看到平台品牌，不显示代理商信息。

### Q3：代理商能看到平台的批发价吗？

代理商只能看到自己的额度余额，看不到平台设置的批发价/倍率。

### Q4：下游用户可以转移到其他代理商吗？

可以，但需要平台管理员操作。代理商自己不能将用户转移。

### Q5：代理商降级为普通用户后，下游用户怎么办？

需要先处理下游用户（转移给其他代理商或转为平台直属），才能降级。
